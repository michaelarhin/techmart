# Hero slideshow images

Drop your 5 hero photos in this folder, named exactly:

- `slide-1.jpg`
- `slide-2.jpg`
- `slide-3.jpg`
- `slide-4.jpg`
- `slide-5.jpg`

They will appear automatically in the landing-page hero slideshow.

Recommended: landscape images, at least 1200×900px, JPG or WebP.
If a file is missing, a matching stock image is shown instead, so the
hero never looks broken. You can change the filenames/order in
`src/pages/LandingPage.tsx` (the `HERO_SLIDES` array).
